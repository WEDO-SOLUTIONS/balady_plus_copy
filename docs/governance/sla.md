## Overview

These SLAs define the maximum acceptable response and resolution times for critical team activities.

---

## 📋 SLA Targets

| Activity | Target |
| -------- | ------ |
| PR Review Time | ≤ 24 hours |
| High Priority Bug Fix | ≤ 48 hours |
| Task Status Updates | Daily (mandatory) |
