## Overview

Ownership KPIs measure the engineer's accountability, independence, initiative, and adherence to team processes.

---

## 📌 10. End-to-End Responsibility

**Definition:** Full ownership of the task lifecycle — from implementation to delivery.

| Metric | Target |
| ------ | ------ |
| % of tasks completed without external fixes | ≥ 90% |

---

## 📌 11. Problem Solving

**Definition:** Ability to resolve issues independently without unnecessary escalation.

| Metric | Target |
| ------ | ------ |
| Number of unnecessary escalations | Minimal |

---

## 📌 12. Proactiveness

**Definition:** Taking initiative to improve the system beyond assigned tasks.

**Measured By:**

- Refactoring contributions
- Performance improvements
- Technical suggestions and proposals

---

## 📌 13. Workflow Adherence

**Definition:** Following TFS + Git standards consistently.

**Measured By:**

- Correct task status updates
- Proper branch naming conventions
- PR linkage to tasks
