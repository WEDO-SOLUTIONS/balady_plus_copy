## Overview

Collaboration KPIs measure how effectively an engineer contributes to team success through code reviews, responsiveness, and knowledge sharing.

---

## 📌 14. Code Reviews

**Definition:** Contribution to reviewing team code.

**Measured By:**

- Number of reviews completed
- Quality and depth of review feedback

---

## 📌 15. PR Turnaround Time

**Definition:** Speed of reviewing pull requests assigned for review.

| Metric | Target |
| ------ | ------ |
| PR review response time | ≤ 24 hours |

---

## 📌 16. Knowledge Sharing

**Definition:** Supporting and mentoring team members.

**Measured By:**

- Technical sessions delivered
- Documentation contributions
- Peer support and mentoring activities
