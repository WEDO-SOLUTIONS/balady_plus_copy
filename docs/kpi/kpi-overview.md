## 🎯 Objective

Each engineer is evaluated across **4 core dimensions** to ensure balanced performance measurement that rewards both delivery speed and engineering quality.

---

## 📊 Evaluation Dimensions

| Category | Weight | Description |
| -------- | ------ | ----------- |
| [Delivery](delivery-kpis.md) | 30% | Task completion, on-time delivery, estimation accuracy |
| [Quality](quality-kpis.md) | 30% | Bug rate, PR quality, architecture compliance, CI/CD stability |
| [Ownership](ownership-kpis.md) | 25% | End-to-end responsibility, problem solving, proactiveness |
| [Collaboration](collaboration-kpis.md) | 15% | Code reviews, PR turnaround, knowledge sharing |

---

## 📈 Final Score Formula

```
Final Score =
  (Delivery × 30%) +
  (Quality × 30%) +
  (Ownership × 25%) +
  (Collaboration × 15%)
```

---

## 👤 Ownership Rule

- Each task must have **ONE owner**.
- Shared ownership is **not allowed**.
- Others may support but are not accountable.
