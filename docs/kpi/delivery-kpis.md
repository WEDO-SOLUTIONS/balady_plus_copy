## Overview

Delivery KPIs measure the engineer's ability to complete work on time, accurately estimate effort, and minimize sprint disruptions.

---

## 📌 1. Task Completion

**Definition:** Ability to deliver tasks end-to-end without reassignment.

| Metric | Target |
| ------ | ------ |
| % of tasks completed fully by the assigned owner | ≥ 90% |

---

## 📌 2. On-Time Delivery

**Definition:** Delivering tasks within agreed timelines.

| Metric | Target |
| ------ | ------ |
| Completed tasks on time / total tasks | ≥ 85% |

---

## 📌 3. Estimation Accuracy

**Definition:** Accuracy of effort estimation.

| Metric | Target |
| ------ | ------ |
| Difference between estimated vs actual effort | ±20% deviation |

---

## 📌 4. Sprint Spill-over Rate

**Definition:** Tasks carried over to the next sprint.

| Metric | Target |
| ------ | ------ |
| Spill-over tasks / total sprint tasks | ≤ 10% |
