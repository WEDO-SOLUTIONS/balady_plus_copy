## Overview

A task is **NOT complete** unless all of the following criteria are met. No exceptions.

---

## ✅ Completion Criteria

| # | Criterion | Required |
| - | --------- | -------- |
| 1 | Clean Architecture followed | ✅ |
| 2 | No critical bugs | ✅ |
| 3 | PR approved by reviewer(s) | ✅ |
| 4 | Fully tested (including edge cases) | ✅ |
| 5 | Ready for release | ✅ |
